# 三科学习工具链验收

日期：2026-09-30。复用原数学工具循环、暂停作答和确定性评分，新增中文、英文客观题；不是新增三个独立 Agent。

## 实现范围

- 学习会话、待答题和主题成绩按用户、学科隔离；旧数学记录、主键及既有知识点编号保留，SQLite 事务迁移可重复执行。
- 模型调用共享学习工具并明确学科；旧数学工具固定 Mathematics，作为兼容入口保留，不重复挂载。
- 中英文阅读模式要求原文，保存后由 `ask_user(learning_attempt_id, question_ids)` 读取服务端题干、原文与选项，不经过普通澄清问题的 800 字截断。
- 同批学习工具按模型给出的顺序执行，避免提交落库与状态读取竞态；相同答案重交返回旧结果，不同答案重交拒绝。
- 题目、答案键和评分归服务端；作答卡片校验当前用户及聊天，只能读取待答练习，不返回答案键。

## 真实模型检查

模型：运行设置中的 `deepseek-flash`，未挂知识库。隔离临时数据库，同一聊天依次执行三科真实 Agent 循环，答复回调固定选择 A；三科均出现：

`get_learning_state → create_learning_practice → ask_user → submit_learning_answer`

| 学科 | 生成题目 | 保存结果 |
| --- | --- | --- |
| 数学 | x²−6x+k=0 有相等实根，正确答案 k=9 | 0/1 |
| 中文 | 根据短句判断「馬虎」含义，正确答案「粗心大意」 | 1/1 |
| 英文 | Last month / The guide ... ___ us，正确答案 led | 0/1 |

逐科重新读取状态均为 completed，答案和解析人工核对可解释。固定选 A 只是测试输入，得分不是模型准确率。首轮中文文本仅一句、英文题偏语法，暴露阅读模式仍用了默认词汇/语法主题；已将未指定主题的阅读模式默认改为阅读理解，并在浏览器复核。

浏览器中文检查：真实生成带原文的阅读理解题；在等待作答时刷新，重连后相同题目与原文仍在，选择 A 后服务端保存 1/1。示例为小明听从妈妈提醒带伞而免于淋雨。测试运行目录的原数学数据库已在迁移前通过 SQLite backup 保存，原开发目录数据未修改。

同一浏览器会话继续切换英文、数学：英文生成图书馆因安装空调缩短营业时间的短文，选择 B，保存 1/1；数学读取到迁移前 Discriminant 的 1/1 记录，再生成 `kx²+4x+2=0` 两相异实根条件题，选择 C（k<2 且 k≠0），保存 1/1。这验证了新科目接入与旧数学记录复用。模型额外调用代码执行验证数学时，运行环境缺少 sympy；该辅助调用失败，但已完成的核心评分和落库不受影响，本轮未扩充代码执行环境。

最后在同一会话让模型分别读取三科状态：三科最近成绩均为 1/1、无待答题，学习会话 ID 各不相同；数学原 Discriminant 累计记录由 1/1 更新到 2/2，未形成新旧编号两份成绩。独立代码复核修正了数学旧编号兼容与同批读写竞态后，未发现阻塞问题；代码复核不替代上述实际运行检查。

## 使用边界

仅四选一客观题；作文、开放题和口语维持原入口，不纳入此评分链。确定性评分不保证模型答案键一定正确。用户回答仍由现有 Agent 转为提交参数；未新增跨进程暂停栈恢复，也未验证多工作进程续答。语料检索质量、题目难度与教学效果不属于本轮结论。
