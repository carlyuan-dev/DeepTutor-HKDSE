示例資料 MATH-01：一元二次方程與判別式
學科：數學必修部分。原創基礎練習筆記，非官方試題或完整考綱。

一元二次方程的一般形式為 ax^2 + bx + c = 0，其中 a 不等於 0。
判別式 D = b^2 - 4ac。D > 0 時有兩個相異實根；D = 0 時有一個二重實根；D < 0 時沒有實根。求根公式為 x = (-b ± sqrt(D)) / (2a)。

例一 MATH-02
x^2 - 5x + 6 = 0，可因式分解為 (x-2)(x-3)=0，因此 x=2 或 x=3。代回原式均得到 0。
常見錯誤：由兩因式乘積等於零，必須分別令每一因式等於零，不能只保留其中一根。

例二 MATH-03
2x^2 + 4x + 5 = 0 的 D = 4^2 - 4(2)(5) = -24，所以沒有實根。a=2、b=4、c=5，計算時不能漏掉 a。

參數題 MATH-04
x^2 - 6x + k = 0 有二重實根，故 36 - 4k = 0，得 k=9；方程成為 (x-3)^2=0，二重根是 x=3。

圖像聯繫 MATH-05
y = ax^2 + bx + c 的實根對應圖像與 x 軸交點的橫坐標。D > 0 有兩個交點，D = 0 與 x 軸相切，D < 0 沒有交點。拋物線開口方向由 a 的正負決定，不由 D 決定。
